# Simple Notes 1.0.0

Första leveransen av en lokal antecknings-PWA med kronologiskt flöde, vanliga sektioner och möten, åtgärder, viktiga anteckningar, sökning, IndexedDB-lagring och full backup/restore via `.snotes`.

Build, 18 automatiska tester, lint, typkontroll och statisk PWA-verifiering passerar. Browserprov och live deployment ingår inte i den verifierade leveransen. Se `docs/release-readiness.md`.
